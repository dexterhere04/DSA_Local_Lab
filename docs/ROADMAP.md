# Phased Roadmap

## 0.1 (Current)
- Java-first AI DSA generation.
- Monaco coding workspace.
- Local Java run/submit with hidden tests.
- Local topic explorer and submission history.

## 0.2
- Better prompt controls (difficulty, tags, pattern constraints).
- Problem sets CRUD UI.
- AI explanation after failed submission.
- Download generated Java template files.

## 0.3
- Multi-language templates: C++, Python, Rust.
- Language-specific function signature generators.
- Side-by-side complexity and approach feedback.

## 0.4
- Spaced repetition and progression engine.
- Practice sessions and streaks.
- Offline problem pack import/export.

## 1.0
- Visualizers for graph traversals, heap operations, DP tables.
- Plugin system for custom prompt packs and topic packs.
